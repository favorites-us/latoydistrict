# IBM Plex Sans

Locally hosted Latin and Latin-extended variable font files, sourced from pickycamper's pinned Google Fonts assets. Unmodified font binaries; SIL Open Font License 1.1 is included in IBMPlexSans-OFL.txt. See https://github.com/google/fonts/tree/main/ofl/ibmplexsans.

One family is used for titles, body text, controls and numeric data. Files retain their content-fingerprinted names. The Latin subset includes Spanish characters. No runtime or build-time Google Fonts request is needed.
