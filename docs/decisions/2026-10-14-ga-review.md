# LA Toy District GA 분석과 콘텐츠 보강 판단

2026-10-14 기준, **자연검색 유입에는 지속적인 증가 신호가 있다. 하루 이내의 콘텐츠 보강 실험을 진행할 가치는 있으며, 추가 광고비와 대규모 개발을 정당화할 사업 성과는 아직 확인되지 않았다.**

GA 실측 확보 전의 판정 보류 의견을 갱신한다. 기존 Search Console 재개 기준은 미판정으로 유지한다. 이번 권고는 GA에서 확인한 검색 유입과 업체 탐색 증가에 근거한 제한된 실험 제안이다. 사이트 변경이나 광고 집행을 수행한 기록은 아니다.

## 사업성 해석과 계측 한계

검색 유입은 하루 평균 약 **6.9세션**이다. 전체 사용자는 거의 그대로이고 참여율도 내려갔다. Direct 세션은 79→51회, AI Assistant 세션은 50→46회로 감소했다. 검색 채널의 성장이 사이트 전체 성장과 동일한 크기는 아니다.

자연검색 사용자의 외부 클릭은 **1명·1회→16명·18회**다. 최근 18회 중 Google Maps 링크가 8회, 업체 웹사이트가 3회, Cylex 디렉터리가 7회다. 업체 정보를 더 찾아보는 신호로는 유용하지만 실제 연락·방문·구매 전환으로 세지 않는다. 낮은 기준값 때문에 증가율도 강조하지 않는다. [행동과 채널](../../artifacts/ga-review-20261014/behavior-by-channel.json), [외부 클릭 목적지](../../artifacts/ga-review-20261014/click-destinations.json).

최근 `lead_submit`과 `store_inquiry` 이벤트는 없었다. 다만 GA에 접수 이벤트가 없는 것과 실제 외부 문의가 없다는 것은 구분해야 한다. DB와 이메일 수신함은 이번 분석에서 조회하지 않았다. 전체 운영 기간에는 **7/19 Google 유료 검색에서 `lead_submit` 1건**이 기록되어 있다. 테스트 여부와 실제 처리 여부는 확인되지 않았고 Q4의 새 문의로 간주하지 않는다. [과거 제출 이벤트](../../artifacts/ga-review-20261014/historic-lead.json).

주요 이벤트 설정은 `purchase`와 `manual_event_PAGE_VIEW`이며 `lead_submit`, `store_inquiry`가 포함되어 있지 않다. 따라서 `keyEvents=0`만으로 문의가 없다고 판단하면 안 된다. 이번 분석은 이벤트 이름별 발생 여부를 별도로 확인했다. [주요 이벤트 설정](../../artifacts/ga-review-20261014/key-events-config.json).

`store_view`는 초기 `gtag` 준비 전에 실행되면 유실될 수 있는 코드 구조다. 최근 해당 이벤트 사용자는 61명인데 업체 경로 기준 사용자는 104명이다. 차이 전부의 원인을 특정할 수는 없지만 완전한 업체 열람 지표로 사용하기 어렵다. 본문의 업체 페이지 지표는 `pagePath`로 직접 집계했다. [계측 코드](../../web/components/StoreViewEvent.tsx), [문의 저장 코드](../../web/app/api/leads/route.ts).

문의 API는 DB 저장까지만 구현되어 있고 자동 알림이나 업체 전달 코드는 없다. 수동 처리 체계가 있는지 확인해야 한다. AdSense 승인·실제 수익도 확인하지 않았으므로 수익 규모를 추정하지 않는다.

## 권고하는 보강 범위

**총 8시간 이내, 추가 광고비 없이 한 차례 보강**을 권한다. 시간이 부족하면 아래 순서대로 범위를 줄인다. 연락·영업 사실은 공개된 공식 자료나 실제 확인을 통해 채우고, 확인 방법과 날짜를 표시한다.

1. **문의와 행동 측정부터 정리한다.** 저장 성공·운영자 인지·후속 처리까지 확인하고 사용자 안내를 실제 운영과 맞춘다. 성공한 문의 이벤트의 주요 이벤트 지정과 `store_view` 초기화 순서를 점검한다. 본인 테스트와 실제 외부 문의를 구분한다.
2. **홈페이지에서 업체를 고르는 데 필요한 정보를 보강한다.** 확인된 업체의 취급 품목, 소매 구매 가능 여부, 영업시간, 연락 수단을 비교할 수 있게 한다. 미확인 사실로 추천 순위나 영업 상태를 만들지 않는다.
3. **이미 조회된 업체 5곳을 먼저 보강한다.** 아래 페이지는 최근 전체 페이지뷰를 기준으로 선정했다. 모두 자연검색의 직접 랜딩 상위라는 뜻은 아니다.

4. **명확한 데이터 품질 문제를 선별 정리한다.** California Balloon House와 `/C`는 주소·전화가 같은 중복 후보이고, LTSC는 공식 홈페이지에서 지역사회·주거·사회서비스 기관으로 소개된다. 업체별 확인 후 병합·분류 수정 범위를 정한다. 현장 확인일이 없다는 이유로 모든 업체 페이지를 일괄 검색 제외하지 않는다. [LTSC 공식 사이트](https://www.ltsc.org/).
5. **방문 가이드는 기존 정보의 정확도를 높인다.** 주차·방문 시간·구매 준비물의 출처와 확인일을 갱신한다. 이번 실측만으로 대량의 신규 가이드를 제작할 근거는 부족하다.

191개 레코드 중 전화번호는 31곳, 영업시간은 2곳이고 현장 확인일·최소주문량·결제수단은 모두 비어 있다. 전체 정비를 한꺼번에 추진하면 작업 상한을 지키기 어렵다. [업체 데이터](../../web/data/stores.json).

## 기존 기준과 다음 판단

[7월에 정한 기준](phase2-verdict.md)은 Q4 중 Search Console 월 노출 2,000회 이상, 월 유기 클릭 100회 이상, 또는 실제 인바운드 문의·클레임 1건 이상이면 최소 재개안을 검토하고, **12/1에 최종 판단**하는 것이다.

현재 서비스 계정으로 접근 가능한 Search Console 목록에는 이 도메인이 없었다. **GA의 Google 자연검색 160세션을 Search Console 160클릭으로 치환하지 않는다. 기존 기준의 충족 여부는 아직 미판정이다.** [Search Console 접근 확인](../../artifacts/ga-review-20261014/gsc-access.json).

10/18까지 보강을 마친다면 10/19~11/15의 28일을 측정하고 처리 시간을 둔 11/18에 검토할 수 있다. 자연검색 세션 192회, 자연검색 업체 열람 사용자 76명, 참여 세션 91회와 비교하고 실제 외부 문의를 따로 확인한다. 계측을 수정한 지표에는 변경일을 표시한다. 전후 차이를 콘텐츠 변경의 인과효과로 단정하지 않는다.

12/1 최종 판단일은 유지한다. GSC 접근을 확보해 기존 기준을 검증하고, 미달이 확인되면 기존 아카이브 계획을 적용한다. 그때도 측정이 불가능한 항목은 미달과 구분해 기록한다. 이번 검색 성장만으로 추가 개발이나 지출 범위를 자동 확대하지 않는다.

## 클로드 검토와 최종 반영

Claude Code에 실제 GA 집계와 기존 기준을 전달해 독립 검토를 받았다. **작업 상한을 정한 보강 실험에 가치가 있고 대규모 투자 근거는 부족하다**는 방향은 일치했다. Claude는 총 12시간 상한을 제안했으며, 최종 권고는 우선 8시간 이내와 업체 5곳으로 좁혔다. [Claude 원문](../../artifacts/ga-review-20261014/claude-ga-review.json).

Claude 원문의 “진짜 외부 문의 0건”, “기존 게이트를 통과하지 못했다”는 표현은 확보한 증거보다 강하므로 채택하지 않았다. 정확한 상태는 **최근 GA 제출 이벤트 없음, 실제 수신 여부 미확인, 기존 GSC 기준 미판정**이다. 또한 주간 유입은 최근 네 주 모두 과거보다 높은 수준이지만 매주 연속 증가한 것은 아니다. 앞의 업체 경로별 채널 분석은 별도로 확인해 최종 판단에 반영했다.
