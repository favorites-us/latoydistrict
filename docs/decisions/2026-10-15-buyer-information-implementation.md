# 바이어 안내 구현 결과

2026-10-15. [선행 검토](2026-10-15-buyer-information-and-photos.md) 이후 사용자의 “진행해봐” 요청으로 구현했다. 기존 배포·커밋·푸시 요청을 이어 같은 Vercel 프로젝트와 Git 브랜치에 반영한다. 최종 배포 상태는 [배포 기록](../../artifacts/buyer-information-implementation-20261015/deployment.json)을 기준으로 확인한다.

## 반영한 내용

- 기존 방문·도매 기초·파티 기획자·점포 운영자·온라인 리셀러 가이드 5종을 영문·스페인어로 정리했다. 출처 없는 도매 비율, 현금 선호, 주차가격, 직원·재고·재입고 패턴, 보관 불가, 제품 안전·정품 일반화를 제거했다.
- 지역 공통 주차·하역은 LADOT, 교통은 Metro 여행 계획, 재판매 서류는 CDTFA, 리콜·제품별 안내는 CPSC 공식 링크에 연결했다. 적용 범위와 열람일을 표시한다.
- `/guide/buying-checklist`와 `/es/guide/buying-checklist`를 추가했다. 업체 4곳의 구매 안내, 중립 질문 6개, 업체별 견적·픽업을 손으로 기록하는 인쇄용 양식을 제공한다. 상단 메뉴·홈·기존 가이드·사이트맵에서 접근할 수 있다. 양식은 입력값을 수집하거나 전송하지 않는다.
- 공식 사이트가 확인된 American Silk, California Balloon House, Casa Manga, Tom’s Model에 구매 전 질문을 각각 추가했다. 질문은 확인된 조건이나 없는 서비스 목록으로 표시하지 않는다.
- 동일 4개 업체에 공식 온라인 카탈로그의 품목·사진 탐색 안내를 추가했다. 이미지 파일은 복제하지 않고 원본 사이트로 연결한다. 온라인 카탈로그를 매장 재고·도매 가격·공인 판매자 인증으로 해석하지 않는다.
- California Balloon House의 반품·오배송 정책을 새 구매 안내로 채택했다. 신고 기한의 `48 business hours`를 양 언어에서 보존했다. Tom’s Model의 템플릿처럼 보이는 반품 문구와 과거 배송 중단 공지는 채택하지 않았다.
- 홈·푸터의 전체 공급처 수록·일괄 현장 검증을 암시하는 문구를 등록 기반 명부와 출처가 있는 온라인 보강으로 정리했다. 등록 자료의 날짜와 가이드 검토일을 구별했다.
- 좁은 화면의 본문 여백, 중간 화면의 메뉴 접힘, 키보드 포커스, 인쇄 시 가이드 본문·버튼 숨김과 기록선을 추가했다. 실제 브라우저·인쇄 시각 확인은 아래 제한 사항에 해당한다.

등록 업체 191개는 그대로다. 기존 구매·서비스 안내 11개에 카탈로그 안내 4개와 반품 정책 1개를 더해 **온라인 안내 16개**가 됐다. 카탈로그 링크 4개를 새 영업 사실 4개나 최신 외관 사진 4개로 세지 않는다. 연락처, 좌표, 현장 확인일 등 관련 없는 업체 필드는 변경하지 않았다. 원천은 `pipeline/data/reviewed-stores.json`이며 사이트 데이터는 재생성했다.

## 사진 점검 결과

조사 전에 정확한 주소와 호수를 고정한 위 4곳만 점검했다. 공식 홈페이지·소개·카탈로그와 제한된 Commons 검색에서 **현재 점포 일치, 촬영일, 재사용 권리를 모두 확인한 외관 사진은 0개**였다. 사진이 존재하지 않는다는 뜻이나 전체 191개 업체의 확보율 추정은 아니다. 공식 HTML의 이미지 존재만으로 외관 사진이라고 판정하지 않았다.

이전 검토에서 찾은 2011년 Commons 지역 사진은 현재 점포용으로 채택하지 않았다. 업체 연락, 촬영, 이미지 다운로드, Google 이미지 추출은 하지 않았다. 다음 사진 작업은 권리자가 제공한 원본이나 사용권이 명확한 촬영 자료를 받는 시점에 진행할 수 있다. ## 검증과 Claude 검토

실제 Claude CLI에 변경한 콘텐츠·질문·양식·표시 코드를 전달해 도구 없는 구현 검토를 한 번 더 수행했다. 응답 메타데이터는 `claude-opus-5-5`다. 스페인어의 주 외 구매자 표현·구매 출처 문서·소매업자 주문 의미와 반품 정책 링크 문구를 수정했다. 루트 링크 오류와 메모 칸 폭 오류 주장은 실제 함수와 기본 CSS를 대조해 채택하지 않았다. Claude의 입력에 기본 CSS 전체가 없었음을 기록했다. [검토 원문](../../artifacts/buyer-information-implementation-20261015/claude-implementation.txt), [판정](../../artifacts/buyer-information-implementation-20261015/claude-disposition.json)

- 기존 데이터 테스트 16개 통과.
- 최종 Next 프로덕션 빌드 통과, 593개 페이지 생성.
- 생성된 HTML 22개 검사 통과: 홈 2개, 가이드 12개, 업체 상세 8개.
- 신규 안내의 양 언어 본문·출처·열람일, 호수, 미확인 시간, 질문 표시, 언어별 내부 링크, canonical/hreflang, 신규 사이트맵 경로를 확인했다.
- 191개 업체의 관련 없는 필드 불변과 데이터 재생성의 바이트 동일성을 확인했다.
- 운영 HTTP 검사 결과는 [운영 검사](../../artifacts/buyer-information-implementation-20261015/production-checks.json)에 별도로 기록한다. HTTP 검사는 브라우저 JavaScript 실행이나 실제 문의 제출이 아니다.

브라우저 도구는 기존 `http://localhost:3017/stores/american-silk-inc-340` 접근을 **저장된 사용자 차단 설정** 때문에 거절했다. 호스트·포트·브라우저·CDP·렌더링 도구를 바꿔 우회하지 않았다. 브라우저 화면, 모바일 화면, 인쇄 미리보기와 실제 GA 이벤트 수신은 미확인이다. 로컬 검증은 빌드 산출물의 파일 분석으로 수행했다. [검증 기록](../../artifacts/buyer-information-implementation-20261015/validation.json)

## 관찰 시 구분할 사항

10월 14일 배포 후 원래 관찰 창인 10월 15일~11월 11일에는 이번 추가 변경도 포함된다. 배포 시각과 바뀐 페이지를 구분해 기록한다. 기존 12월 1일 최종 판단 일정은 유지한다. 문구·탐색·구매 준비표 변경의 전환 효과나 사진보다 높은 효용이 입증된 것은 아니다. 문의 처리와 GSC 접근은 여전히 별도 과제다.

근거 없는 내용을 줄이는 작업과 새 기능의 수요 검증은 다르다. 이후 바이어가 어떤 질문에서 막히는지 관찰하되, 지금 확보한 연락 클릭이나 적은 정성 응답을 구매 완료·매출로 계산하지 않는다.
