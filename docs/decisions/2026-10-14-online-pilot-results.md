## 재수집과 측정

검토 자료를 생성된 `stores.json`과 분리했다. 재빌드 때 기준 데이터와 승인된 필드 근거를 합치며 상호·주소·호수·ZIP이 다르면 중단한다. 디렉터리는 빈 전화번호 채움만 허용하고 기존 번호나 출처 등급 교체를 금지한다. 공식 출처 URL과 추가 웹사이트 주소는 업체별 검토 도메인과 대조한다. 대면 확인일은 갱신하지 않는다.

기존 OSM의 주소 또는 이름만 일치해도 병합하던 조건을 이름·주소·호수 모두 일치해야 하는 후보 생성으로 바꿨다. 무료 수집 스크립트는 좌표·분류를 포함해 후보 파일만 만들며, 사이트 파일을 직접 덮어쓰지 않는다. [작업 지침](../../pipeline/CONTACT-RESEARCH-C.md)

전화·이메일·웹사이트·구매 근거 링크에 `store_contact_click`을 추가했다. 자체 이벤트에는 업체 slug와 클릭 종류만 넣는다. 구매 근거 열람은 약한 관심 지표이고, 전화·이메일 클릭도 문의 완료는 아니다. 기존 GA 외부 링크 클릭과 합산하지 않는다. 배포 후 실제 GA 수신 및 업체별 분해 설정은 별도 확인해야 한다.

## Claude 검토와 확인

Claude CLI의 `claude-opus-5-5`로 증거 요약과 코드를 검토했다. Claude가 원문을 독립적으로 브라우징한 것은 아니다. [1차 검토](../../artifacts/online-pilot-20261014/claude-pilot-review.txt)

좌표를 null로 덮어쓰는 경로, 디렉터리 번호 교체 가능성, 공식 도메인 검증, 출처 표시 누락, 매장·온라인 채널의 혼동 가능성을 수정했다. 포트폴리오 문구도 일부 신청자에게 해당함을 양 언어에 표시했다. 새 디렉터리 번호는 출처 맥락이 사라지는 JSON-LD 전화 필드에 넣지 않았다.

Claude가 Casa Manga의 로그인·이메일 신청 경로와 Funland의 미국 hobby distributor 분류에 근거가 없다고 지적한 부분은 원문과 대조했다. Casa Manga 홈페이지의 배너·도매 안내와 Jada의 섹션 제목이 직접 뒷받침하므로 해당 내용은 유지했다. [후속 검토](../../artifacts/online-pilot-20261014/claude-followup-review.txt)에서 Claude는 해당 지적을 철회했고, 제공된 로컬 구현에 중대 차단 사유가 없으며 제한적 진행 판단에 동의했다.

후속 검토가 요청한 다른 노출 위치도 코드로 확인했다. 목록 카드는 전화번호를 표시하지 않으며, 검토된 도매·소매 배지에는 온라인·매장 구매 옵션을 상세 페이지에서 확인하도록 안내했다. 검색은 상호·주소·분류를 사용하고 소매 방문 가능 여부 필터는 없다. sitemap은 URL 목록만 내보낸다. 후보 자료의 기준 데이터 병합은 여전히 수작업이며, 생성 결과 전체를 복사하지 않도록 지침과 기준 데이터 검증을 뒀다.
