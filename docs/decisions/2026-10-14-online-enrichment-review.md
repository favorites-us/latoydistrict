# Toy District 온라인 정보 확보 검토

검토일: 2026-10-14 · 대상: 상점 연락처, 영업시간, 취급 품목, 구매·도매 조건

**온라인 정보 보강은 진행할 가치가 있다. 우선순위는 공식 사이트의 상세 거래 안내, 별칭을 통한 공식 출처 발견, 사업주가 제출하는 정보의 순서다.** 실제 공개 페이지에서 기존 데이터에 없는 최소 주문금액, 일반 고객 이용 여부, 도매 신청 경로, 응대 언어를 찾았다. 다만 검색 수요가 높은 업체에서도 공식 운영 정보를 찾지 못하는 경우가 있어, 191개 전체의 정보 확보율을 보장할 근거는 없다.

이번 작업은 공개 웹 조사, 기존 수집 코드 검토, Claude CLI 교차 검토다. 운영 데이터·사이트를 수정하거나 업체에 연락하지 않았다. 사이트 투자 판단은 [앞선 GA 검토](2026-10-14-ga-review.md)의 제한된 파일럿 권고를 유지한다.

## 1. 현재 확보 수준과 이번 조사 범위

[현재 데이터](../../web/data/stores.json)의 191개 레코드 중 전화번호는 31개, 영업시간은 2개, 웹사이트 링크는 9개다. 최소 주문, 결제수단, 재판매 증명서 필요 여부는 모두 비어 있다. 링크와 전화가 있다는 사실이 현재 유효성이나 정확한 업체 매칭을 보장하지는 않는다.

이전 소유 채널 조사 결과는 191개 중 `found:true` 9개, 디렉터리 전화 조사 결과는 185개 중 25개였다. 두 조사 결과는 겹치므로 합산할 수 없으며, 검색 실패가 온라인 정보의 부재를 증명하지 않는다.

이번에는 GA 수요 상위 5곳과 공식 웹 경로의 확보 가능성을 확인할 7곳, 총 12곳을 목적에 따라 골랐다. 무작위 표본이 아니므로 전체 확보율로 환산하지 않는다. 검색에는 상호·주소·호수, 별칭, 일부 SNS·스페인어 변형을 사용했다. 모든 업체에 모든 검색 경로를 소진한 전수 조사는 아니다.

검색어는 아래 순서로 넓힌다. 발견한 주소·별칭·연락처만 다음 검색에 사용한다.

```text
"상호" "주소 또는 호수" -site:toydistrictlosangeles.com
"등록 DBA 또는 확인된 별칭" wholesale / contact / catálogo / mayoreo
"정확한 주소" toys / wholesale / instagram / facebook
"확인된 사업용 전화번호"
"취급 제조사" distributor / where to buy → 해당 업체 확인
```

먼저 영어와 실제 발견한 별칭을 사용하고, 스페인어·한국어·중국어 표기가 발견되면 그 변형을 추가한다. 모든 상호를 임의 번역해 검색하는 방식은 우선순위를 낮춘다. 자체 사이트와 그 내용을 복제한 페이지는 새 증거에서 제외한다.

원문 확인은 도메인별 이용 조건을 확인한 후 필요한 몇 페이지만 대상으로 한다. 허용되는 HTML·구조화 데이터·PDF를 읽고, 렌더링·이미지 확인은 정보가 그 안에 있을 때 추가한다. 차단된 채널의 우회나 전체 상품 카탈로그 복제는 수집 계획에 포함하지 않는다.

## 4. 항목별 검증과 보존

정보 단위는 ‘업체 하나의 신뢰도’가 아니라 **특정 업체의 특정 항목에 대한 증거**다.

- **동일 업체 판정:** 상호 또는 검증된 별칭과 정확한 주소·호수를 기본으로 삼는다. 주소가 불완전하면 다른 신뢰 출처의 사업용 전화·도메인 연결을 추가한다. 같은 건물이라는 이유만으로 합치지 않는다. 이름만 유사한 후보는 검토 대기다.
- **적용 범위:** 도매/소매, 웹 주문/매장 방문, 일반 영업/특정 서비스, 주문금액/상품 수량을 구분한다. 출처가 범위를 밝히지 않았다면 ‘미명시’로 남긴다.
- **최신성:** 오늘 조회한 날짜와 원문 작성·갱신 날짜를 분리한다. 작성일이 없으면 현재도 동일하다고 보증하지 않는다. 최초 운영 기준으로 시간은 30일, 연락·거래 조건은 90일마다 재확인을 제안하며 변경·신고가 있으면 앞당긴다.
- **성과 구분:** 신규 채움, 오류 정정, 기존 값 재확인, 충돌을 별도 집계한다. 웹사이트 재발견이나 전화 재확인은 신규 정보로 세지 않는다.
- **원문 확인:** AI는 검색·추출·불일치 탐지를 돕고, 채택은 원문과 업체 매칭을 다시 확인한다. 같은 내용을 두 모델이 동의했다고 독립 출처 두 개가 되는 것은 아니다.

최소 증거 구조의 예시는 다음과 같다. 이는 구현 제안이며 현행 데이터 형식 변경이 아니다.

```json
{
  "store_id": "american-silk-inc-340",
  "field": "minimum_order_value",
  "value": 3000,
  "currency": "USD",
  "scope": "wholesale; published on account application page",
  "scope_unknowns": ["walk-in applicability", "first versus repeat orders"],
  "source_url": "https://www.americansilkinc.com/wholesale",
  "source_type": "first_party_site",
  "identity_evidence": "same official domain publishes matching address and phone",
  "observed_at": "2026-10-14",
  "source_dated_at": null,
  "change_type": "new_fill",
  "decision": "reviewed_candidate",
  "method": "online_checked"
}
```

실제 증거에는 필요한 최소 원문 발췌·위치, 검토자, 접근 조건, 동일 원천 그룹, 변경 이력도 보관한다. 전체 페이지 복사를 기본으로 삼지 않는다. 사용자 화면에는 출처와 확인일을 붙이고, 온라인 확인을 현장 확인용 `verified_at`에 넣지 않는다.

공개 정보만으로 해결되지 않는 최소 주문·결제·증명서 조건은 사업주 제출 경로가 필요하다. 짧은 정정 폼에 공개 상호·주소, 연락처, 대표 품목, 거래 조건, 근거 링크와 게시 동의를 받는 방식이 적합하다. 외부 메시지 발송은 이번 작업에 포함하지 않았다.

## 5. 수집 전에 정리할 기존 코드와 출처 정책

1. [05-build.mjs](../../pipeline/05-build.mjs)의 73–84행은 보강 필드를 `null`로 만들고 결과 파일을 다시 쓴다. 승인된 보강 정보를 생성 파일 밖의 별도 파일로 보존하고 매번 재적용해야 한다.
2. [07-contact.mjs](../../pipeline/07-contact.mjs)의 41–47행은 `found`, 신뢰도, 필수 출처를 검사하지 않는다. 65행의 출처 조건은 개별 레코드 변경이 아닌 누적 카운터를 사용한다. 채택된 항목만 출처와 함께 병합하고, 오래된 값의 변경은 검토된 정정으로 처리해야 한다.
3. [06-free-enrich.mjs](../../pipeline/06-free-enrich.mjs)의 127–138행은 주소 일치 **또는** 이름 유사도로 후보를 받으며 호수 검증이 없다. 상호·주소·호수의 일관성을 확인하고, 정보가 부족한 후보는 자동 채택하지 않아야 한다.
4. [현행 조사 지침 B](../../pipeline/CONTACT-RESEARCH-B.md)는 Google Maps/Places/Business Profile을 출처에서 제외하고, 디렉터리는 전화에만, 영업시간은 사업주 웹사이트에만 허용한다. 이를 유지하면서 소유가 확인된 호스팅 스토어, 제조사 등재·별칭, 거래 조건 항목의 취급을 지침에 명시하는 것이 좋다. 이것은 프로젝트 규칙이며 모든 사이트의 법적 이용 가능성을 보증하는 문서가 아니다.

## 6. 8시간 파일럿과 확장 판정

앞서 제안한 제한된 파일럿은 정보 확보와 검증을 먼저 판정하는 데 배분한다. 아래 시간과 기준은 실행을 위한 제안값이며 수확량 예측이 아니다.

| 시간 | 작업·산출물 |
|---|---|
| 0.5시간 | 유효 상점·중복 점검, 출처 규칙과 항목별 증거 구조 확정 |
| 1시간 | GA 상위 5곳의 남은 공식 채널·번호·호수 문제 탐색. 이미 한 검색은 반복하지 않음 |
| 2.5시간 | 앞의 업체군 및 웹사이트 링크 보유군과 겹치지 않는 유효 상점 20곳을 무작위 선정해 조사. 선정 명단·방식 보존 |
| 1.5시간 | 웹사이트 링크 보유군 최대 9개에서 상세 구매 안내 확인. 이미 확인한 내용과 유효하지 않은 상점은 분리 |
| 1시간 | 채택 후보 전부와 보류 사례 일부를 원문으로 재검토 |
| 1시간 | 검토된 보강 데이터·출처, 개선될 페이지 예시, 확보 비용과 결과 정리 |
| 0.5시간 | 예비 시간 |

세 업체군의 성과를 따로 보고한다. 무작위군도 나머지 업체군의 탐색 수율을 보는 것이며, 전체 191개에 대한 정밀 통계 추정은 아니다. 파일럿 시작 전에 이미 발견한 이번 사례는 기존 확보분으로 표시한다.

조사 상한은 일반 업체당 약 7분, 검색 6회·관련 원문 8페이지 중 먼저 도달하는 것으로 제안한다. 중요한 충돌은 GA 우선군 시간 안에서 검토한다. 새 별칭·공식 URL 같은 단서 없이 상한에 도달하면 미확보로 기록한다.

확장 판단은 다음처럼 구분한다.

- **다음 소규모 묶음으로 확대:** 무작위 20곳 중 3곳 이상에서 새 구매 판단 정보·실사용 연락 경로 또는 유의미한 정정을 얻고, 수집·검수 시간당 채택 항목 2건 이상이며, 채택 자료에 미해결 업체 오매칭이 없는 경우. 대표 품목의 단순 나열이나 이미 있는 전화 재확인만으로 통과시키지 않는다.
- **공식 경로 보유군에 집중:** 무작위군 개선이 2곳이거나 수집 효율이 기준에 미달하지만 공식 출처군에서는 유용한 정보가 나오는 경우. 이때 광범위한 자동 수집 투자를 확대하지 않는다.
- **탐색 확대 보류:** 무작위군 개선이 0–1곳이거나 동일 매칭 방식에서 반복 오류가 발견되는 경우. 확보된 올바른 정보는 활용하고, 미공개 정보는 사업주 정정·제출 경로로 확보한다. 오류가 있는 매칭 방식은 수정 후 다시 검증한다.

어떤 판정에서도 미해결 업체 오매칭은 게시하지 않는다. 연락 클릭·공식 사이트 이동·실제 문의는 별도 성과 지표로 본다. 기존 GA에 외부 링크 클릭은 있으므로 이를 활용하되, 전화·이메일·문의 이벤트의 현재 계측 상태를 확인해 정보 획득 성과와 사업 성과를 구분한다.

## 7. Claude 검토를 반영한 최종 판단

로컬 Claude CLI로 수집 증거와 코드 문제를 전달해 비판적 검토를 받았다. 실행 결과 모델은 `claude-opus-5-5`다. Claude가 독립적으로 웹을 조회한 것은 아니며, 제공한 원문 조사 결과를 검토했다. [검토 원문](../../artifacts/online-enrichment-20261014/claude-review.txt)을 함께 보관한다.

반영한 지적은 다음과 같다.

- 수요 상위군과 공식 사이트가 풍부한 군의 수율을 섞지 않는다.
- 기존 연락처 재확인과 새 구매 정보 확보를 구분한다.
- 무작위로 고른 나머지 업체군에서 증분을 확인한 뒤 확장한다.
- 보강 데이터 보존과 출처별 검증을 먼저 확보한다.

다만 Claude의 일부 단정은 수정했다. 온라인으로 전체 업체를 확보할 수 없다고 확정할 근거는 없으며, 현재 확인한 범위가 제한적이다. American Silk의 $3,000 조건도 ‘웹 주문에만 적용’이라고 단정할 수 없다. 공식 도매 가입 페이지에 명시됐고 매장 방문 적용 여부는 미확인이라고 표현한다. 이 업체는 현재 `gifts`로 분류돼 있으므로 Claude가 언급한 ‘장난감 분류 수정’은 해당하지 않는다. SNS 역시 공식 웹사이트에서 링크되지 않았다는 이유만으로 전부 버리면 사이트 없는 업체를 놓친다. 다른 강한 식별 근거로 소유 관계를 확인하되 현행 영업시간 출처 제한은 유지한다. Claude의 판정안에서 빠진 중간 성과 구간은 위의 세 단계 판정으로 보완했다.

**최종 의견:** 구매자가 실제로 쓸 수 있는 정보가 온라인에 남아 있고, 기존 조사 범위를 넓히면 추가 확보가 가능하다. 가장 먼저 확보할 것은 공식 도매 안내·연락 경로·일반 고객 이용 여부다. 제조사 목록과 별칭 검색으로 공식 출처 발견을 보완하고, 공개되지 않은 조건은 사업주 제출로 쌓는다. 정보량보다 정확히 식별된 업체의 새로운 구매 판단 정보가 얼마나 늘었는지로 투자를 결정하는 것이 타당하다.
