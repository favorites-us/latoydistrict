# 후속 검토: merchant pilot 수정본

## 1. 첫 리뷰의 오탐 정정

- **Casa Manga:** 두 주장 모두 철회합니다. 근거는 두 가지입니다. 홈페이지 상단 배너에 도매 고객은 로그인해야 할인가가 보인다고 명시되어 있습니다. 도매 계정 안내 문구는 "Wholesale Sign Up / Log In" 또는 sales@casamanga.com으로 신청하라고 지시합니다. 즉 추론이 아니라 직접 출처입니다. 218 Boyd #D 주소와 기존 전화번호도 같은 페이지에서 일치합니다.
- **Jada Toys:** 철회합니다. "Hobby distributors → United States" 아래 468 E 4th, 90013에 Funland Toys / FLT Collectibles가 나옵니다. 현재 문구는 재고나 영업을 보장하지 않는 귀속 진술로 정확합니다.
- **출처 라벨:** California Balloon의 `/pages/faq` 제목은 실제로 "About Us & Contact Us"입니다. American Silk `/wholesale`에는 실제 신청 양식이 있습니다. 라벨 변경은 불필요하며, 제 지적은 오탐이었습니다.

## 2. 수정 사항 확인 (제공된 코드 기준)

모두 코드에서 확인했습니다.

- null 좌표 보호: `coordinates[key] != null`
- 상속 연락처의 충돌 검출: `checkInherited`
- 디렉터리 출처의 `correction` 금지
- business 출처 도메인 검증과 디렉터리 denylist
- 디렉터리 전화번호를 JSON-LD `telephone`에서 제외
- `06`의 쓰기 대상이 `pipeline/out/` 후보 파일로 한정됨
- 베이스라인에 생성 필드가 들어오면 거부됨

"both" 배지가 붙은 세 상점에는 온라인 판매 범위와 매장 확인 안내 문구가 붙어 있습니다. 포트폴리오 문구도 EN/ES 모두 "일부 신청자"로 수정됐습니다.

## 3. 남은 구체적 블로커

**로컬 구현 기준으로는 제공된 코드와 데이터에서 하드 블로커를 찾지 못했습니다.** 아래 항목은 배포 전에 닫아야 할 조건부 항목과 사소한 결함입니다.

1. **미제공 화면은 검증할 수 없습니다.** 대상은 `StoreCard`, 목록과 필터, 검색 인덱스, sitemap 등입니다. 확인할 점은 두 가지입니다.
   - "both" 배지가 한정 문구 없이 노출되거나, "retail" 필터에 매장 소매로 잡히는지
   - 디렉터리 전화번호가 출처 라벨 없이 노출되는지

   `StorePage`와 `jsonld.ts`만으로는 판단할 수 없습니다. 배포 전에 해당 파일을 확인해야 합니다.
2. **브라우저 시각 QA 미실시.** 사용자 권한 거부로 막힌 상태이며, 정적 HTML 검사와 Next build로 대체했다고 정확히 기록돼 있습니다. 로컬 구현에는 문제가 없지만 배포 전 잔여 위험으로 남습니다.
3. **가드 회귀 테스트 출력이 제공되지 않았습니다.** 다음 경우를 단위 테스트로 고정할 것을 권합니다.
   - null 좌표
   - 상속값 충돌
   - 디렉터리 `correction`
   - 미검토 도메인
   - 디렉터리 출처의 비전화 필드

   현재 근거는 코드 리딩뿐입니다.
4. **사소한 결함 (블로커 아님)**
   - `links.website`의 **값** 호스트가 `business_domains`에 속하는지 검사하지 않습니다. 현재 Tom's Model은 일치하지만 스키마가 보장하지는 않습니다.
   - 기존 전화번호를 디렉터리가 `reconfirm`하면 `field_sources.phone`이 directory로 덮어써집니다. 그 결과 더 강한 출처가 있어도 JSON-LD 전화번호가 빠집니다. 현재 데이터에는 해당 사례가 없습니다.
   - 06 후보를 베이스라인에 수작업으로 병합하는 단계는 주석에만 의존합니다. 검토된 값(예: 디렉터리 전화번호)이 생성 필드만 제거된 채 복사된 뒤 리뷰 항목이 삭제되면, 출처 없는 "상속값"이 됩니다. 병합 스크립트나 diff 검사를 권합니다.

## 4. 판단

**LIMITED GO 판단에 동의합니다.** 범위는 알려진 공식 사이트 콘텐츠로 한정하고, 광범위 크롤러나 롱테일 구매 조건 확장은 하지 않습니다.

수율 기록은 그대로 정확하게 유지해야 합니다.
- 새 디렉터리 전화번호는 20곳 중 4곳입니다.
- 새 소유자 조건은 0건입니다.
- 기존 공식 사이트 4곳과 제조사 1곳은 신규 수율이 아닙니다.
- 시간당 노동 지표는 측정하지 않았습니다.

조사자는 Codex로 기록돼 있습니다. 이 검토는 별도의 비평이며 인간 승인을 대체하지 않습니다.
