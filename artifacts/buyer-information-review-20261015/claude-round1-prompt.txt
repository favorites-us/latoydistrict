PRIMARY SOURCES OPENED TODAY (concise paraphrases, not independent legal advice)
1. Google Geo Guidelines: https://about.google/brand-resource-center/products-and-services/geo-guidelines/
Street View Web/apps permits supported embed/API use generally, but explicitly prohibits screenshots/removing imagery from embedded sources; additional restrictions include deriving data/digitizing, application-based extraction, and downloading for separate use. Google Maps ordinary map screenshot guidance must not be conflated with Street View. Fair use is case specific; Google does not decide it.
2. Maps Platform Terms: https://cloud.google.com/maps-platform/terms (3.2.3)
Restricts scraping/export/storage, caching except exceptions, and creating derived content. 3.2.3(d)(iii) explicitly mentions use of Core Services in a listings/directory service. 3.2.3(e) includes Street View alongside non-Google maps. Thus API existence is NOT a blanket green light for this directory. Exact commercial implementation requires resolving applicable terms; do not assert court-determined illegality.
3. Service-specific terms: https://cloud.google.com/maps-platform/terms/maps-service-terms
Places API may be displayed without a corresponding map but not with a non-Google map; Places UI Kit has its own explicit non-Google-map exception. A product-specific exception does not automatically authorize photo rehosting or all directory use.
4. Embed API billing: https://developers.google.com/maps/documentation/embed/usage-and-billing
Currently no charge/unlimited requests, API key required; explicitly remains subject to license restrictions. Other imagery APIs are not assumed free.
5. Street View Static policies: https://developers.google.com/maps/documentation/streetview/policies
Pano IDs have a storage exception; this does not grant a general right to save image files as our own photo library. Attribution and applicable app policies apply.
6. Places policies: https://developers.google.com/maps/documentation/places/web-service/policies
Photo attribution and source-photo access required; use depends on API/terms, not downloading Google Maps UI photos.
7. Mapillary help: https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data
Says contributed imagery is CC BY-SA with contributor/source/license attribution. Coverage, capture dates, image/license version, API access and separate terms have NOT been checked for these shops.
8. Commons reuse: https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
Each file has its own creator/license requirements; public accessibility does not remove them. Toy District category found, but no proof of current storefront coverage.
9. LADOT colored curbs: https://ladot.lacity.gov/residents/colored-curb-zones
Commercial yellow-zone loading differs from ordinary-car passenger/baggage loading; posted signs/other restrictions also govern. Useful district-level loading guidance, not proof of a particular shop's loading zone.
10. LADOT parking meters FAQ: https://ladotparking.org/parking-meters/faq/
Meter prices vary by area and sometimes time; spaces cannot be reserved. No basis for a universal $3/hour district quote or current vacancy promises.
11. CDTFA: https://www.cdtfa.ca.gov/industry/new-permit-and-license-holders/managing-your-sales.htm
Seller's permit copy is not a substitute for a resale certificate. Store account approval, wholesale pricing, and tax documentation must be separated. This does not supply individual-store eligibility.
