# 상인 사진 확보 방법과 바이어 정보 제품 검토

## 0. 요약

- **구글 Street View 스크린샷을 우리 사진으로 쓰는 것은 하지 마세요.** 구글 가이드라인이 명시적으로 금지합니다. 이미지 저작권도 구글에 있습니다. "무조건 불법"이라고 단정할 수는 없습니다. 다만 계약 위반이고 저작권 침해 소지가 있으며, 공정이용 주장에 기댈 근거도 약합니다.
- **임베드처럼 지원되는 표시 방식도 이 디렉터리에는 바로 쓸 수 없습니다.** 3.2.3(d)(iii)은 리스팅/디렉터리 용도를, 3.2.3(e)는 non-Google 지도(MapLibre)와의 병용을 다룹니다. 이 두 조항 해석이 끝나기 전에는 쓰면 안 됩니다.
- **비용과 위험이 가장 낮은 대안은 구글 Maps 화면으로 나가는 외부 링크입니다.** 다만 이것도 "우리 사진"이 아니고, 검증 근거로 쓸 수도 없습니다.
- **가설의 큰 방향(소수 상인의 출처 있는 구매조건 + 방문 전 체크리스트)에는 동의합니다.** 그러나 두 가지는 수정이 필요합니다.
  - "비교(comparison)"라는 틀은 빼야 합니다. 현재 9개 상인은 서로 대체재가 아닙니다.
  - 체크리스트에 대한 수요 근거가 없습니다. 이 부분을 먼저 검증해야 합니다.

## 1. 이미지: 계약 · 법 · 표시 vs 소유

| 구분 | 성격 | 판단 |
|---|---|---|
| **Street View 스크린샷 저장·재게시** | Geo Guidelines가 명시적으로 금지(계약). 이미지 저작권은 구글 보유(법) | ❌ 사용 불가. "불법 확정"은 아니지만, 계약 위반과 침해 위험을 감수할 이유가 없습니다 |
| **Street View에서 정보 추출** (예: 간판 보고 상호·유닛 번호 기록) | "deriving data/digitizing" 제한 + 프로젝트 정책(구글을 DB 입력원으로 쓰지 않음) | ❌ 사진을 저장하지 않더라도, 눈으로 보고 DB에 옮겨 적는 것 자체가 이 범주에 해당할 수 있습니다 |
| **Embed API (Street View 모드)** | 현재 무료·API 키 필요. 라이선스 제한은 그대로 적용 | ⚠️ 미해결. 상인별 페이지에 넣는 순간 3.2.3(d)(iii) 디렉터리 조항과 겹칩니다. 같은 페이지에 MapLibre 지도가 있으면 3.2.3(e)와도 충돌할 수 있습니다. 해석이 확정되기 전에는 쓰지 마세요 |
| **Places API 사진** | 출처 표기·원본 접근 요건. non-Google 지도와 함께 표시 불가 | ❌ MapLibre 구조에서는 사실상 막혀 있습니다. UI Kit 예외가 있어도 사진 재호스팅이나 디렉터리 전반의 사용까지 허용하는 근거는 아닙니다 |
| **Street View Static의 pano ID 저장** | ID만 저장할 수 있는 예외 | ⚠️ 이미지 파일을 우리 자산으로 저장할 권리는 아닙니다. 유료 API이고, 디렉터리 조항 문제는 그대로 남습니다 |
| **구글 Maps로 가는 일반 외부 링크** | 우리 앱 안에서 Core Services를 쓰지 않음 | ✅ 위험이 가장 낮습니다. 다만 프로젝트 정책이 "구글 = DB 입력원 금지"인지, "구글 링크도 금지"인지는 소유자가 확인해야 합니다 |
| **상인 공식 웹사이트 사진** | 상인이나 사진가의 저작물. 공개되어 있다고 라이선스가 생기지 않음 | ❌ 무단 복제는 하지 마세요. **링크만 거는 것은 가능**합니다 |
| **Mapillary** | CC BY-SA. 기여자·출처·라이선스 표기 필요 | ⚠️ 원본 그대로 표시하고 출처를 표기하면 가능성이 있습니다. 다만 크롭·합성 등 2차 저작물은 BY-SA로 공개해야 하는지 검토가 필요합니다. 커버리지, 촬영일, API 약관은 **미확인**입니다 |
| **Wikimedia Commons** | 파일별 라이선스 | ⚠️ 지구(district) 분위기 사진으로는 쓸 수 있습니다. 현재 점포 커버리지는 **미확인**입니다 |
| **직접 촬영 / 소유자 제공 원본** | 우리가 권리를 보유하거나 명시적으로 허락받음 | ✅ 가장 깨끗합니다 |

**법적 맥락 (법률 자문이 아니며, 확인이 필요합니다)**
- 미국 저작권법은 공공장소에서 보이는 건축물 사진에 대해 일반적으로 예외를 둡니다.
- 간판 위의 로고는 식별 목적이라면 상표 문제 위험이 낮은 편입니다. 다만 간판의 독창적인 그림은 별도 저작물일 수 있습니다.
- 사진에 사람 얼굴이 찍히면 블러 처리하는 것이 실무상 안전합니다.

**가설에 대한 판단:** "소유자 제공·직접 촬영 > CC 자산 > 외부 링크"라는 우선순위는 근거와 맞습니다. 합성 점포 이미지를 실제 증거처럼 쓰지 않는다는 원칙에도 동의합니다.

## 3. 가설 공격

### 제거하거나 수정해야 할 것
1. **"비교(comparison)" 틀.** 풍선, 실크플라워, 모형, 만화 매장은 서로 대체재가 아닙니다. 9개 매장으로 비교 UI를 만들면 빈 칸만 많은 표가 됩니다. "상인별 카드"로 충분합니다.
2. **기존 가이드의 미출처 문장들** (도매 90%, 현금 선호, 보관 안 해줌, 주차 요금 범위, Metro 주소). 새 제품을 만들기 전에 **삭제하거나 "확인할 질문"으로 바꾸는 작업이 가장 먼저**입니다. 출처 기반 제품을 표방하면서 이 문장들을 남겨 두면 신뢰가 깎입니다.
3. **"일반 체크리스트가 차별점"이라는 전제.** 서류 구분 같은 내용은 AI 답변이나 CDTFA 사이트에서도 얻을 수 있습니다. 차별점은 지구별·상인별 조건과 결합할 때만 생깁니다.

### 사진이 텍스트보다 나을 수 있는 경우
- **길찾기와 매장 식별.** 점포가 빽빽하고 간판·유닛 번호가 헷갈리는 지구에서는 첫 방문자에게 점포 사진 한 장이 텍스트 세 문단보다 유용할 수 있습니다. 영어가 약한 사용자에게는 더 그렇습니다.
- **존재 확인 신호.** 191개는 실제 영업 중인지 검증한 목록이 아닙니다. 날짜가 찍힌 직접 촬영 사진은 "이 날 이 간판이 있었다"는 **영업 여부 근거를 겸합니다.** 온라인 조사로는 이 정보를 얻을 수 없습니다.
- **비교 시사점.** 그래서 짧은 현장 도보는 사진 확보보다 **영업 여부 확인 수단**으로서 온라인 조사를 크게 앞설 수 있습니다. 공공 거리에서 외관만 촬영하면 상인 접촉 없이도 가능합니다. 다만 이는 사용자가 결정할 사항이며, 이번 범위 밖의 비교안으로만 제시합니다.

### 수요 근거가 없는 부분
- 측정된 문의 이벤트는 두 기간 모두 0입니다. 오가닉 세션 130→192는 작은 표본입니다. **어떤 정보 유형을 원하는지 보여 주는 데이터는 하나도 없습니다.**
- 검색어가 매장명이나 "toy district hours/parking" 위주라면, 사용자는 위치·시간·사진을 원하는 것이고 체크리스트는 원하지 않는 것입니다. 이 경우 가설의 1~2순위가 뒤집힙니다.
- 커밋 기록상 현재는 **12/1까지 무비용 관찰 국면**입니다. 새 제품 구축보다 기존 데이터 분석이 그 국면에 맞습니다.

## 4. 후속 실험 (소규모, 반증 가능)

**질문:** "구매 방법/조건" 의도가 실제로 존재하는가? 사진을 온라인에서 합법적으로 조달할 수 있는가?

### A. 수요 측: Search Console 검색어 의도 분류
- **입력:** 이미 비교했던 두 28일 기간의 검색어와 노출수. 쓰기 작업은 없고 읽기만 합니다.
- **분류 버킷:** ① 매장명/위치 ② 영업시간 ③ 구매조건/도매/resale ④ 주차·교통 ⑤ 품목/브랜드 ⑥ 기타
- **산출물:** `query_intent_20261015.csv` (query, impressions, clicks, bucket, 분류자 메모)
- **반증 규칙 (사전에 정하는 판단 기준이지, 효과 예측이 아닙니다):**
  - ③의 노출 비중이 매우 낮으면(예: 5% 미만) "체크리스트 우선" 가설을 약화로 기록합니다.
  - ①이 지배적이면 사진·위치 제품의 우선순위를 올립니다.
- **한계:** 노출이 적으면 결론을 내리지 않고 "판단 불가"로 기록합니다.

### B. 공급 측: 고정 샘플 20개의 시각 자료 가용성
- 기존 무작위 20개 샘플을 그대로 씁니다. 상인별로 다음을 기록합니다.
  - (a) Commons/Mapillary에 해당 점포가 식별되는 이미지가 있는지, 촬영일, 라이선스 버전
  - (b) 공식 사이트에 명시적 라이선스가 있는 사진이 있는지
  - (c) 공식 갤러리 링크가 있는지
- **Street View는 열람하지도, 기록하지도 않습니다** (정보 추출 제한 + 프로젝트 정책).
- **산출물:** `visual_coverage_sample20.csv` (merchant_id, source, url, license, capture_date, identifiable_storefront Y/N, minutes_spent)

### 시간 기록과 중단 조건
- 상인별 소요 분을 기록합니다. 총 상한은 **A 1시간, B 2시간**입니다.
- **B 중단 조건:** 처음 10개에서 사용 가능한 CC 점포 이미지가 1개 이하이거나, 상인당 중앙값이 15분을 넘으면 즉시 중단합니다. 이 경우 "온라인 사진 조달 = 링크 전용"으로 확정합니다.
- **B 판단 규칙:** 20개 중 사용 가능한 CC 이미지가 5개 이상이면 출처 표기 갤러리를 소규모로 파일럿할지 검토합니다. 5개 미만이면 링크 전용으로 갑니다.

## 5. 불확실성과 판단을 바꿀 증거

| 불확실성 | 현재 상태 | 판단을 바꿀 증거 |
|---|---|---|
| 임베드가 3.2.3(d)(iii)/(e)에 해당하는지 | 사용자의 요약만으로는 결론 불가 | 조항 원문 전체 해석, 또는 구글이나 변호사의 서면 확인. 허용으로 확인되면 Embed가 링크보다 우선합니다 |
| Mapillary/Commons 커버리지 | **미확인** | 실험 B 결과 |
